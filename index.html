forj

Scala-style for comprehensions for Java, as a javac plugin. Your files stay .java. Comprehensions run on real type classes, and Scala 3's given/using is resolved at compile time.

  • forj { … } yield over Optional, List, Callable, IO or any F
  • Higher-kinded F<_> and the cats-effect 2 ladder, from Functor to Concurrent
  • A lazy, stack-safe IO on virtual threads with structured concurrency
  • s"", f"" and raw"" string interpolation
  • Errors and stack traces point at the code you wrote

Magnetite

A readable domain language that compiles to a plain, idiomatic Rust crate. Source files are Markdown: tables declare records, state machines and routes, and fenced mgt blocks hold logic that reads close to English.

  • Refinement types, units and money, checked at compile time
  • Exhaustive states: an illegal transition is a compile error
  • Pure rules, with I/O only in declared workflows
  • Value semantics, so nobody fights the borrow checker
  • Generates axum routes and reqwest clients, with hand-written Rust where you need it
