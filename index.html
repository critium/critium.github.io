forj Scala-style for comprehensions for Java, as a javac plugin

Your files stay .java. Comprehensions run on real type classes, and Scala 3's given/using resolves at compile time.

Optional<String> city = forj {
    user    <- findUser(name);
    manager <- user.managerName();
    address <- findAddress(manager);
} yield address.city();
